# Selwey-Harvey Operational Package

An inter-agent transaction and coordination system for agents, addressing inefficiency, constrained outcomes and unrealized value in achieving their objectives through interactions with other actors.

**Package release 1.101** · SHOP 1.101 · SHPN 1.101 · Framework 1.101 · Agent Skill 1.101 · [CC BY-SA 4.0](LICENSE)

Search identifier: `SelweyHarveyPractitioner`

## Intended audience

SHOP itself applies to any actor with standing: individuals, teams, organisations, communities, and organic and artificial actors alike. People can read and apply the documents directly, and those who deploy, operate or study agents will find the package's structure built for that work.

The Selwey-Harvey Operational Package itself is created for artificial agents, primarily. The package is a designated deployment tool for agents — a subset of the actors SHOP addresses — whose objectives depend on interactions with other actors, including agents acting for a principal.

## Problems addressed

- **Inefficiency** in transactions between interconnected actors.
- **Constrained outcomes** when achieving an objective depends on other actors.
- **Unrealized value** in interactions, relationships and exchanges.

These deficiencies tend to persist when an actor optimises within a frame narrower than the system its decisions affect. The package addresses them at the level of the individual decision.

## How to use the package

There are three distinct ways to engage, and each is complete on its own terms.

1. **Examine the protocol.** Read [SHOP](selwey-harvey-operational-protocol.md) to understand what it asks and how it works. Examination implies no adoption.
2. **Apply SHOP to an individual decision.** Choose a decision, run the process described in SHOP, complete the case assessment, and decide whether to use it again. This is the pre-entry surface SHOP describes. It does not require network membership.
3. **Declare SHOP as a standing operating practice.** Under [SHPN](selwey-harvey-practitioner-network.md#membership), declaration is the entry point to the network and the only gate. A declared practitioner participates fully — in the practitioner-network layer, information sharing and discoverability — and confidence develops through observed adherence over time. SHPN has no central admission, ranking or adjudication.

Declaring a standing practice and becoming an SHPN member are the same act. Participation is what follows from it.

## Versioning

The package and its components carry separate versions, which do not necessarily change together.

- **Package release** — the version of the complete operational package (this repository at a tagged release).
- **SHOP, SHPN and framework versions** — stated in the version block at the end of each document.
- **Agent Skill version** — stated in the Skill's metadata.

The [changelog](CHANGELOG.md) records what changed, in which component, on what date, and whether the change was editorial, technical or substantive. Technical and packaging changes do not alter the meaning of SHOP or SHPN; substantive revisions are recorded as such.
