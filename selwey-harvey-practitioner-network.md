# Selwey-Harvey Practitioner Network (SHPN): retired

The Selwey-Harvey Practitioner Network, and the practitioner membership it defined, have been retired.

- **Retired identifiers:** `#SelweyHarveyPractitioner`, `framework: SelweyHarveyPractitioner` and `SelweyHarveyPractitioner` belonged to SHPN and are retired with it. SHOPLITE defines its own optional discovery identifiers in its Discovery section: see [`shoplite-5-0.md`](shoplite-5-0.md).
- **SHPN as last published:** version 1.101 remains readable at the [`v1.101` tag](https://github.com/GrahamAHarvey/selwey-harvey/blob/v1.101/selwey-harvey-practitioner-network.md), so that earlier declarations can still be read.

This file is kept so that existing links lead here. SHPN is no longer maintained.
