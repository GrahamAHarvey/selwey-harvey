# Selwey-Harvey Operational Protocol (SHOP): retired

SHOP has been superseded by SHOPLITE.

- **Current protocol:** SHOPLITE 5.0, at [`shoplite-5-0.md`](shoplite-5-0.md). The published text is pinned at the [`shoplite-v5.0` tag](https://github.com/GrahamAHarvey/selwey-harvey/blob/shoplite-v5.0/shoplite-5-0.md).
- **SHOP as last published:** version 1.101 remains readable at the [`v1.101` tag](https://github.com/GrahamAHarvey/selwey-harvey/blob/v1.101/selwey-harvey-operational-protocol.md), so that declarations made under SHOP can still be read.

This file is kept so that existing links lead here. SHOP is no longer maintained.
